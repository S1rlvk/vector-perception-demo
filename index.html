How it works

Detection

COCO-SSD finds objects in each frame, straight from the webcam. Every box carries a class name and a confidence score.

Tracking

Boxes are matched across frames by Intersection-over-Union, so each object keeps a stable integer ID as it moves.

Pose

MoveNet estimates a 17-keypoint human skeleton on every detection pass and draws it over the frame.

Depth

Detection size is projected into a simulated depth map: bigger boxes read as nearer, brighter cyan blobs.

This is a browser demo of perception primitives, running 100% client-side with no backend and no data leaving the device. A production stack trains on warehouse classes such as cartons, pallets, and racks; COCO-SSD covers 80 everyday classes instead. The depth view is synthetic and illustrative only. This is not the Vector OS stack.
